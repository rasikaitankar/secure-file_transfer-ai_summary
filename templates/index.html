HTTPS via ngrok

ngrok creates a public HTTPS tunnel to your local Flask server. This demonstrates TLS/SSL over HTTP.

# Step 1: Install ngrok
pip install pyngrok

# Step 2: Run in a new terminal
ngrok http 5000

# Or use our helper script
python ngrok_start.py
ngrok gives you a URL like https://abc123.ngrok.io — full HTTPS with valid TLS certificate. Anyone on the internet can access your server securely.
Network Latency Simulator

Simulate slow network conditions. Adds artificial delay to every server request — demonstrates how latency affects file transfer.

Network Latency Concept

Latency = time for a packet to travel from source to destination. Affected by: distance, router hops, congestion. CDNs reduce latency by placing servers close to users.
